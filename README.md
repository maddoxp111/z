# Z

An X/Twitter clone where everyone except you is AI. ~100 real-handle accounts (Ye, Drake, Taylor Swift, Elon, TMZ, Pop Crave, CNN, ESPN…), each with its own persona, voice, topics and posting/reply frequency. News accounts invent fake news as time passes. Like counts keep climbing long after a post goes up, comments are generated by Haiku 5.5 the first time you open a post, and the goal is to get famous — you're verified at **1,000,000 followers**.

All content is AI-generated parody fiction.

## Step-by-step: get it running on Railway (with your `sweet-optimism` database)

### 0. What you need
- The Railway project that contains your Postgres database (**sweet-optimism**).
- An Anthropic API key (Haiku 5.5 = `claude-haiku-5-5`). **Rotate any key you've pasted in chat** and make a fresh one at https://console.anthropic.com/settings/keys.
- This GitHub repo (`maddoxp111/z`), branch `claude/cool-cerf-wwuk0g` (or merge it into `main` first).

### 1. Add the app as a service
1. Open your Railway project → **+ New** → **GitHub Repo** → pick `maddoxp111/z`.
   (First time? Railway will ask you to install its GitHub app — allow access to this repo.)
2. Open the new service → **Settings** → **Source** → set **Branch** to `claude/cool-cerf-wwuk0g` (or `main` after merging).
3. Railway auto-detects Node and runs `npm install` + `node server.js` (see `railway.json`).

### 2. Connect the database
1. In the Z service → **Variables** → **+ New Variable** → **Add Reference**.
2. Name: `DATABASE_URL` → choose your Postgres service (sweet-optimism) → `DATABASE_URL`.
   This uses the private network URL, which needs no SSL setup. (If you use the *public* URL instead, Z enables SSL automatically.)
3. Tables are created automatically the first time the server boots — nothing to run by hand.

### 3. Add your API key
Variables → **+ New Variable**:
| Variable | Value |
|---|---|
| `ANTHROPIC_API_KEY` | your key |
| `POST_MULT` *(optional)* | start speed, default `6` |
| `REPLY_MULT` *(optional)* | default `6` |

### 4. Expose it
Z service → **Settings** → **Networking** → **Generate Domain**. Open the URL, create your account, and the first boot seeds the timeline (takes ~1 minute — refresh if the feed is empty).

### 5. Play
1. **Sign up** (name + handle). You start with 12 followers.
2. **Post** and **comment** on big accounts. Replies from fake people arrive within a couple of minutes; sometimes a celebrity notices you (big follower jump).
3. **Open the Sim tab** (clock icon in the left nav):
   - **+1 day / +1 week / +1 month** fast-forwards the world. **Keep simulating** repeats forever until you stop it.
   - **Live speed** controls how fast the AI accounts post and reply in real time (Real time → Turbo).
   - **Cast** lets you edit every account's posts/day and replies/day.
4. **DM** people from their profile. Big stars brush off nobodies until your followers catch up.
5. Reach **1,000,000 followers** → you get the blue check.

### Cost control (important)
Every post and reply is an API call. Defaults are conservative: the AI accounts **auto-pause when nobody has the site open for 10 minutes** (Sim tab → "Auto-pause"), and fast-forwards are capped by "posts per run". A 1-week fast-forward ≈ 55 Haiku calls + ~20 for replies. Turn on **Pause AI accounts** in the Sim tab if you want the world frozen.

## Import your X account
Open **Your fame → Import your X account** (or `#/import`, or the *Import from X* button on your profile).
1. **Username** → *Look up*. Without an X API token Z can only fetch your profile picture (via unavatar.io). If you set `X_BEARER_TOKEN` on Railway (a paid X API plan), Z also pulls your name, bio, follower count and recent public posts by username.
2. **X archive (recommended, free)**: on X go to *Settings → Your account → Download an archive of your data*, unzip it, and select `tweets.js`, `like.js`, `follower.js`, `account.js`, `profile.js` from the `data` folder. Everything is parsed in your browser, then sent to your own Z server.
3. Tick *this is my own account* → **Import**. Your name, @username, picture, bio, follower count and posts (with their original dates and like counts) move over, and Haiku writes a profile of you (voice, topics, humor, quirks). Every reply, DM and celeb reaction now gets that profile in its prompt. You can see it under **What Z knows about you**, re-import any time, or **Forget imported data**.

Notes: X only exposes likes/followers to the account owner, so likes and the follower count come from the archive. Imported posts don't count toward the game's follower growth (your real follower count does). You can't import onto a handle that belongs to a built-in Z account or another player.

## Running locally
```
npm install
# Postgres running locally, or point DATABASE_URL at Railway's public URL
DATABASE_URL=postgres://… ANTHROPIC_API_KEY=sk-ant-… npm start
```
| env | purpose |
|---|---|
| `DATABASE_URL` | Postgres. Default `postgres://postgres:postgres@localhost:5432/z`. |
| `ANTHROPIC_API_KEY` | Haiku 5.5. Without it Z falls back to canned text. |
| `Z_MODEL` | override the model id (default `claude-haiku-5-5`) |
| `X_BEARER_TOKEN` | optional X API token for username lookups (paid X API plan) |
| `PORT` | default 3000 |
| `TICK_MS` | scheduler period (default 20000) |
| `POST_MULT` / `REPLY_MULT` | default world speed (editable live in the Sim tab) |
| `IDLE_PAUSE` | `false` to keep the AIs posting even when nobody is online |

## Customising the cast
Everything lives in `cast/*.js`. One line per account:

```js
A('SnoopDogg', 'Snoop Dogg', '<bio>', 21 /*M followers*/, 'celeb', 'blue',
  4 /*posts per day*/, 2 /*replies per day*/,
  'voice: how they write (caps, slang, emoji, length)',
  'topics: what they talk about',
  ['sample post A', 'sample post B'])   // style references only
```
- `voice` + `topics` + the two `sample posts` are sent to Haiku with every generation for that account, so tightening them changes how that account sounds.
- `ppd` / `rpd` set how often they post / reply (per simulated day). The Sim tab's global multipliers scale all of them; per-account edits in the Sim tab override the file.
- `kind`: `celeb` | `commentary` | `news`; verified: `blue` (people) or `gold` (organisations).
- Handles/display names/profile pictures mirror the real X accounts (pictures load via unavatar.io; initials appear if one fails).

## How it plays
- **Likes grow over time**: each post stores a target (scaled to the author's followers) and counts approach it exponentially, so a Ye post reaches millions of likes — far more than there are accounts.
- **Replies are lazy**: opening a post asks Haiku for a threaded set of fake-people replies ("Show more replies" for more).
- **Fame**: your posts get likes proportional to your followers; ~8% go viral. Commenting on big accounts gives them a chance to notice you; AI accounts also reply to your posts on their own.
- **DMs**: big accounts ignore or brush off nobodies and warm up as your ratio improves; fans and, later, celebs DM you.
- Gameplay tuning constants are at the top of `server.js`.
