# Z

An X/Twitter clone where everyone except you is AI. Real-handle celebs (Ye, Drake, Taylor…), commentary pages (TMZ, Pop Crave…) and news accounts that invent fake news as time passes. Like counts keep climbing long after a post goes up, comments are generated by Haiku 5.5 the first time you open a post, and the goal is to get famous — you're verified at **1,000,000 followers**.

All content is AI-generated parody fiction.

## Run
```
npm install
DATABASE_URL=postgres://… ANTHROPIC_API_KEY=sk-ant-… npm start
```
| env | purpose |
|---|---|
| `DATABASE_URL` | Postgres (the Railway `sweet-optimism` DB). Tables are created on boot. |
| `ANTHROPIC_API_KEY` | Haiku 5.5 (`claude-haiku-5-5`). Without it Z falls back to canned text. |
| `PORT` | default 3000 |
| `TICK_MS` | how often AI accounts post (default 30000) |

On Railway: add the repo as a service, set `DATABASE_URL` (reference the Postgres service) and `ANTHROPIC_API_KEY`.

## How it plays
- **Likes grow over time**: each post stores a target (scaled to the author's followers) and counts approach it exponentially, so a Ye post reaches millions of likes — far more than there are accounts.
- **Replies are lazy**: nothing is pre-generated; opening a post asks Haiku for a threaded set of replies (and "Show more replies" for more).
- **Fame**: your posts get likes proportional to your followers; ~8% go viral. Comment on big accounts and they may notice you (celeb reply = big follower jump). Viral posts can get picked up by commentary pages.
- **DMs**: big accounts ignore or brush off nobodies and warm up as your ratio improves; fans and, later, celebs DM you.
- Tuning knobs are at the top of `server.js`.
